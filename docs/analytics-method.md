# 分析手法

計算はすべて `src/analytics/` の純粋関数で行い、UIからは独立しています。

## 1. 期待値（`expectedValue.ts`）
オッズ＝的中時の総払戻倍率、確率 p は 0〜1 とします。

- **期待払戻倍率** = p × オッズ
- **期待収益率** = p × オッズ − 1
- **オッズ逆算確率** = 1 ÷ オッズ（控除率を含むため、全買い目の合計は1を超える）
- **損益分岐オッズ** = 1 ÷ p

### 入力検証
| 入力 | 扱い |
|---|---|
| p が null / undefined | エラー `missing` |
| p が NaN・±∞・数値以外 | エラー `not_a_number` |
| p < 0 または p > 1 | エラー `out_of_range`（±1e-9 以内の浮動小数点誤差は丸める） |
| オッズが null | エラー `missing`（未発売・欠場）。期待値は「算出不可」と表示 |
| オッズが NaN・±∞ | エラー `not_a_number` |
| オッズ < 1.0 | エラー `below_minimum`（払戻は最低100円＝1.0倍のため） |
| オッズ ≥ 10000 | 計算はするが `unusually_high` の警告を付ける |
| p × オッズ ≥ 2 | 計算はするが `model_market_divergence` の警告（⚠要検証）を付ける |

閾値で絞り込むときは 1e-9 の許容誤差を入れています。0.5×2.4−1 = 0.19999999999999996 のような誤差で、ちょうど20%の候補が落ちないようにするためです。

## 2. 推定確率（`probabilityModel.ts`）
### モデルの形（条件付きロジット）
すべてのモデルは「特徴量 × 係数」で各艇のスコアを出し、softmax で1着確率にします。

- スコア_i = Σ 係数_k × 特徴量_ik
- P(i が1着) = exp(スコア_i) ÷ Σ_j exp(スコア_j)（欠場艇は除外し0）

| 特徴量 | 定義 | 欠損時 |
|---|---|---|
| 場・コース別1着率（対数） | ln（対象レースの**日付より前**の過去レースで計算した場・コース別1着率） | 過去レース30件未満なら推定しない |
| 級別A1 / A2 / B2 | 該当すれば1（B1が基準） | — |
| 全国勝率 | 勝率 − 5.0 | 差0（平均扱い）にし「欠損」と表示 |
| モーター2連率 | (2連率% − 35) ÷ 10 | 同上 |
| 展示タイム | (タイム − 出走艇の平均) ÷ 0.1秒 | 同上 |

場・コース別1着率は、全場平均をラプラス平滑化 (1着数+1)÷(出走数+6) したうえで、場の値を全場平均に寄せます：(場の1着数 + 30×全場平均) ÷ (場の出走数 + 30)。進入コースは、展示で6艇の進入がすべて分かればそれを使い、分からなければ枠なりとみなします。

### データ漏れの防止
場・コース別1着率は、`CourseRateIndex`（`courseRates.ts`）で**対象レースの日付より前**の過去レースだけから計算します（同日・未来の結果は使いません）。実データでは過去レースと予測対象が同じ成績ファイルから作られるので、これがないとレース自身の結果を使って予測してしまいます。

### 同梱・学習モデル
| モデル | 係数 |
|---|---|
| コース別基準モデル | 場・コース別1着率=1、他は0 |
| 複合デモモデル | 1 / A1 +0.35 / A2 +0.15 / B2 −0.30 / 全国勝率 0.15 / モーター 0.10 / 展示 −0.40（**未検証のデモ値**） |
| 学習モデル | 確定レースから推定した値（§3） |

### 連勝式への展開（Harville 法）
P(i→j→k) = pᵢ × pⱼ/(1−pᵢ) × pₖ/(1−pᵢ−pⱼ)

全買い目の合計は1になります（テストで検証済み）。Harville 法は「2着・3着の争いも1着確率に比例する」と仮定するため、実際には本命の2・3着率を過小評価し、人気薄を過大評価する傾向が知られています。

## 3. 学習と検証（`training.ts`・`evaluation.ts`）
### 手順
1. 結果が確定したレースを日付順に並べ、古い約80%を**学習用**、残りの新しい期間を**検証用**に分けます。同じ日のレースは必ず同じ側に入れます（時系列分割）。
2. 学習用で係数を最尤推定します。平均負の対数尤度 + L2正則化（中心はコース別基準モデル、λ=0.01）を、Adam で400回反復して最小化します。
3. 検証用で、学習モデル・複合デモモデル・コース別基準モデルを同じ指標で比較します。

学習には、学習用200件・検証用100件以上が必要です。

### 指標
- **対数損失**：−ln p(1着艇)。一様予測で ln6 ≈ 1.79。小さいほど良い
- **多クラス Brier スコア**：Σ(pᵢ − 1[i=1着])²。一様予測で約0.83。小さいほど良い
- **本命1着率**：最大確率の艇が1着になった割合

### 「検証済み」の条件
次をすべて満たすときだけ「学習モデル（検証済み）」と表示します。
- 実データ（デモデータではない）
- 検証用レースが300件以上
- 検証期間の対数損失が、コース別基準モデルより小さい

**デモデータで学習した結果は、件数や成績にかかわらず未検証のままです。** サンプルは、モデルと似た構造の乱数で作っているため、評価が甘く出ます。

### 限界
- 検証は「1着の当てはまり」です。実データにはオッズがないため、期待値に基づく買い方の回収率はバックテストできません（払戻金は的中した組だけが分かります）。
- 学習データの「展示タイム」と「進入」は競走成績から取っています。進入は本番のものなので、実際の発走前の判断より情報が多く、精度がやや甘く出る可能性があります。
- 300件程度では、改善が偶然である可能性が残ります。目安として数千レース以上で確認してください。

## 4. 展示情報の集計（`exhibition.ts`）
- 対象指標（すべて小さいほど良い）：展示タイム、直線、回り足、周回展示、展示ST
- 順位は同値が同順位（1,2,2,4…）。欠損と欠場は順位・平均・最良の計算から除外する。
- 艇ごとの平均順位は、値のある指標だけで計算する。全指標が欠損なら null。
- 画面では欠損を「データなし」と表示する。

## 5. 場別・コース別統計（`venueStats.ts`）
- 対象は「過去レース」と「確定レース」を重複なく合わせたものです（`mergeHistorical`）。
- 1着率・2連対率・3連対率の分母は、着順が確定した出走数。
- 条件：場、風速（0〜2 / 3〜4 / 5m以上）、波高（0〜2 / 3〜5 / 6cm以上）、期間。条件を指定したとき、風速や波高が欠損しているレースは対象外にする（0とはみなさない）。
- 対象件数と期間を必ず表示し、100件未満なら「偏りが大きい」と警告する。件数0のときの率は null（0%とは区別する）。

## 6. 振り返り（`history.ts`）
- 照合：確定レースの着順と買い目を比べる。払戻 = 結果の払戻(円/100円) × 購入額 ÷ 100。
- 的中率 = 的中数 ÷ 確定数、回収率 = 払戻合計 ÷ 購入合計。
- 的中したが払戻データがない記録は集計から除外する。結果待ちも除外する。
- **サンプル（source=sample）と実績（source=actual）は混ぜずに別々に集計する。**

## 7. 注目レース（`insights.ts`）
- 推定本命の1着率が40%未満（混戦）
- 1号艇以外が推定本命
- 展示タイムの最速と最遅の差が0.2秒以上

## 8. 表示上の方針
- 推定確率は「未検証のデモモデル」によるものと明示し、利益を保証する表現は使わない。
- 期待収益率の正負は色に加えて ▲▼ でも示す。
- 推定確率がオッズ逆算確率の2倍以上の候補には「⚠要検証」を付ける。乖離が大きいほど、利益機会よりモデル誤差である可能性が高いためです。
