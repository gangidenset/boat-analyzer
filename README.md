# BOAT ANALYZER

競艇の情報（出走表・展示・オッズ・過去成績）をまとめ、レース分析から期待値計算までを一画面群で行う、PC・スマートフォン対応のWebアプリ（MVP）です。

> ⚠ **現在のデータはすべて架空のサンプル（デモデータ）です。** 推定確率は未検証のデモモデルによる参考値で、精度は保証されません。期待収益率がプラスでも利益を保証するものではありません。

## 主な機能
| 画面 | 内容 |
|---|---|
| ダッシュボード | 対象日のレース一覧、注目レース、期待値条件に合う候補、データ更新状況、分析履歴 |
| レース一覧・出走表 | 開催日／競艇場／レース番号／状態で絞り込み、6艇の選手・級別・勝率・モーター・ボート |
| 展示情報比較 | 展示タイム・直線・回り足・周回展示・展示STの比較表とグラフ（欠損は「データなし」） |
| 競艇場別分析 | 場・風速・波高・期間の条件でコース別の1着率／2・3連対率、決まり手。対象件数と期間を表示 |
| オッズ・期待値 | 単勝・2連単・3連単の推定確率、オッズ、期待払戻倍率、期待収益率、取得時刻。絞り込み・並べ替え・記録の保存 |
| 分析履歴 | 保存した予測と結果の照合、的中率・回収率（サンプルと実績を別集計）、モデル検証指標 |
| 設定・データ管理 | サンプル／実データの切替、取得元、更新時刻、候補条件、読み込みログ・エラー |

## 環境構築
必要なもの：Node.js 20.19 以上（22 LTS 推奨）、npm

```bash
git clone <このリポジトリ>
cd boat-analyzer
npm install
```

## 起動
```bash
npm run dev        # 開発サーバ http://localhost:5173
```
本番ビルドを確認する場合：
```bash
npm run build      # 型チェック＋ dist/ に出力
npm run preview    # http://localhost:4173
```
`dist/` は静的ファイルだけなので、任意の静的サーバに置けば動きます（HashRouter を使用）。※デプロイはまだ行っていません。

## 操作方法（例）
1. **ダッシュボード**で対象日のレースと期待値候補を確認する。
2. **レース一覧**で「開催日・競艇場・レース番号」を選び、レースカードをクリックすると出走表が開く。
3. 出走表の「展示情報を比較」「オッズ・期待値を分析」ボタンで各画面に移る。
4. **オッズ・期待値**で券種や期待収益率の下限などを指定し、気になる買い目を「保存」する。
5. **分析履歴**で結果と照合する。確定済みのサンプルレース（2026/10/21）を保存すると、すぐに的中・回収率を確認できます。
6. **設定**で候補条件やモデルを変更する。「実データ」に切り替えると、取得元が未設定である旨のエラー表示を確認できます。

スマートフォンでは画面下部のナビで移動します。表は横にスクロールするか、カード表示に切り替わります。

## サンプルデータ
- 場所：`src/data/sample/*.json`
- 再生成：`npm run generate:sample`（`scripts/generate-sample-data.mjs`。シード固定なので毎回同じ内容になります）
- 内容：開催レース72件（2026/10/21 確定済み、2026/10/22 発走前）、過去レース約1,100件
- 欠場・展示未発表・オッズ未発表・計測欠損・独自展示なしの場など、動作確認用のケースを含みます。
- 選手名・成績・オッズ・結果はすべて架空です。画面には常に「デモデータ」と表示されます。

## 実データ連携に必要な作業
実データの取得は**未実装**です（外部通信はしていません）。連携するには次の作業が必要です。

1. **提供元の確認**：[docs/data-sources.md](docs/data-sources.md) の「未確認事項」を確認する（公式サイトのポリシー全文、ダウンロードデータの利用条件など）。無断スクレイピングやアクセス制限の回避はしません。
2. **取り込み**：公式の競走成績・番組表ファイルを変換するスクリプトを作り、`src/domain/schemas.ts` の形式（欠損は `null`）に変換する。
3. **取得元の実装**：`src/data/actualDataSource.ts` で変換済みデータを読み込み、`validateDataset()` で検証して返す。
4. **秘密情報**：APIキーなどが必要な場合は `.env.example` を `.env.local` にコピーして設定する（コミットしない）。`VITE_` で始まる変数はブラウザに公開されるため、秘密のキーはサーバ側のプロキシで扱う。
5. **モデル検証**：実データで `src/analytics/evaluation.ts` を使ってモデルを検証し、係数を推定し直す（[docs/analytics-method.md](docs/analytics-method.md)）。
6. 有料契約・デプロイ・外部へのデータ送信は、事前に承認を得てから行う。
