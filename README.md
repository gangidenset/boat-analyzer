# BOAT ANALYZER

競艇の情報（出走表・展示・オッズ・過去成績）をまとめ、レース分析から期待値計算までを一画面群で行う、PC・スマートフォン対応のWebアプリ（MVP）です。

> ⚠ **現在のデータはすべて架空のサンプル（デモデータ）です。** 推定確率は未検証のデモモデルによる参考値で、精度は保証されません。期待収益率がプラスでも利益を保証するものではありません。

## 主な機能
| 画面 | 内容 |
|---|---|
| ダッシュボード | 対象日のレース一覧、注目レース、期待値条件に合う候補、データ更新状況、分析履歴 |
| レース一覧・出走表 | 開催日／競艇場／レース番号／状態で絞り込み、6艇の選手・級別・勝率・モーター・ボート |
| 展示情報比較 | 展示タイム・直線・回り足・周回展示・展示STの比較表とグラフ（欠損は「データなし」） |
| 競艇場別分析 | 場・風速・波高・期間の条件でコース別の1着率／2・3連対率、決まり手。対象件数と期間を表示 |
| オッズ・期待値 | 単勝・2連単・3連単の推定確率、オッズ、期待払戻倍率、期待収益率、取得時刻。絞り込み・並べ替え・記録の保存 |
| 分析履歴 | 保存した予測と結果の照合、的中率・回収率（サンプルと実績を別集計）、モデルの学習と検証 |
| 設定・データ管理 | サンプル／実データの切替、公式データの取り込み、更新時刻、候補条件、分析記録の書き出し・読み込み、ログ・エラー |

## 環境構築
必要なもの：Node.js 20.19 以上（22 LTS 推奨）、npm

```bash
git clone <このリポジトリ>
cd boat-analyzer
npm install
```

## 起動
```bash
npm run dev        # 開発サーバ http://localhost:5173
```
本番ビルドを確認する場合：
```bash
npm run build      # 型チェック＋ dist/ に出力
npm run preview    # http://localhost:4173
```
`dist/` は静的ファイルだけなので、任意の静的サーバに置けば動きます（HashRouter を使用）。このブランチへのプッシュで `.github/workflows/deploy.yml` が GitHub Pages に自動公開します。

## 操作方法（例）
1. **ダッシュボード**で対象日のレースと期待値候補を確認する。
2. **レース一覧**で「開催日・競艇場・レース番号」を選び、レースカードをクリックすると出走表が開く。
3. 出走表の「展示情報を比較」「オッズ・期待値を分析」ボタンで各画面に移る。
4. **オッズ・期待値**で券種や期待収益率の下限などを指定し、気になる買い目を「保存」する。
5. **分析履歴**で結果と照合する。確定済みのサンプルレース（2026/10/21）を保存すると、すぐに的中・回収率を確認できます。
6. **設定**で候補条件やモデルを変更する。公式データを取り込むと「実データ」モードで実際のレースを表示できます（下記）。

スマートフォンでは画面下部のナビで移動します。表は横にスクロールするか、カード表示に切り替わります。

## スマートフォンのホーム画面に追加する
GitHub Pages（https://gangidenset.github.io/boat-analyzer/ ）で公開しています。PWA（manifest・アイコン・Service Worker）に対応しているので、ホーム画面に追加するとアプリのように全画面で起動できます。
- **iPhone（Safari）**：共有ボタン（□↑）→「ホーム画面に追加」。Chrome など Safari 以外のブラウザでは追加できない場合があります。
- **Android（Chrome）**：右上の︙ →「ホーム画面に追加」または「アプリをインストール」。

Service Worker はネットワークを優先し、オフラインのときだけ前回表示した内容を出します。
アイコン（PNG）は `scripts/generate-icons.mjs` が `npm run dev` / `npm run build` の前に自動で生成します（生成物はコミットしません）。

## サンプルデータ
- 場所：`src/data/sample/*.json`
- 再生成：`npm run generate:sample`（`scripts/generate-sample-data.mjs`。シード固定なので毎回同じ内容になります）
- 内容：開催レース576件（10/7〜10/20 学習用の確定レース〔オッズなし〕、10/21 確定済み、10/22 発走前）、過去レース612件
- 欠場・展示未発表・オッズ未発表・計測欠損・独自展示なしの場など、動作確認用のケースを含みます。
- 選手名・成績・オッズ・結果はすべて架空です。画面には常に「デモデータ」と表示されます。

## 実データ（公式データ）の取り込み
公式サイトで公開されている **番組表（B）と競走成績（K）** を取り込んで使えます。アプリから公式サイトへの自動アクセスはしません。

1. **利用条件の確認**：BOATRACE公式サイトのサイトポリシーとデータダウンロードページで、利用条件を確認してください（[docs/data-sources.md](docs/data-sources.md) の「未確認事項」）。
2. **ダウンロード**：公式サイトの「データダウンロード」から、番組表と競走成績のファイル（LZH形式）をご自身でダウンロードします。
3. **解凍**：7-Zip などで解凍し、テキストファイル（例：`B261020.TXT`、`K261020.TXT`）を取り出します。
4. **取り込み**：アプリの「設定・データ管理」→「実データの取り込み」→「ファイルを選んで取り込む」で、テキストファイルを選びます（複数可。同じレースを再度取り込むと新しい方で置き換えます）。
5. **切り替え**：「実データモードに切り替える」を押すと、取り込んだレースが表示されます。

データはこの端末のブラウザ内（IndexedDB）にだけ保存されます。設定画面から削除できます。

**公式データに含まれないもの**：オッズ（そのため実データでは期待値を計算できません）、直線・回り足・周回展示・展示ST。推定確率には、対象日より前の過去レースが30件以上必要です。

## モデルの学習と検証
「分析履歴」→「モデルの学習と検証」の「学習を実行」で、確定レースから予測モデルの係数を推定します。古い期間で学習し、新しい期間で検証します（詳しくは [docs/analytics-method.md](docs/analytics-method.md)）。
- 実データで検証用300件以上、かつ基準モデルより良い場合だけ「検証済み」になります。デモデータでの学習は常に「未検証」です。
- 学習後は「学習モデルを使う」で、推定確率をこのモデルに切り替えられます。

## 分析記録のバックアップ
「設定・データ管理」→「保存データ」から、分析記録を JSON で書き出し・読み込みできます（PCとスマートフォンの間の移行にも使えます）。
